# راهنمای نصب و اجرا

این راهنما برای اجرای محلی TaskFlow روی ویندوز، macOS یا Linux نوشته شده است.

## ۱. پیش‌نیازها

- PHP نسخهٔ 8.1 یا بالاتر
- MySQL نسخهٔ 8.0 یا MariaDB سازگار
- افزونه‌های PHP: pdo، pdo_mysql و mbstring
- Git (اختیاری)

## ۲. دریافت پروژه

    git clone https://github.com/dyfiydkyckg-create/TaskFlow.git
    cd TaskFlow

## ۳. ساخت پایگاه داده

فایل database/schema.sql را در phpMyAdmin وارد کنید یا با خط فرمان اجرا کنید:

    mysql -u root -p < database/schema.sql

این فایل پایگاه دادهٔ taskflow و جدول tasks را می‌سازد.

## ۴. تنظیم اتصال

متغیرهای محیطی زیر را در محیط PHP خود تنظیم کنید:

- DB_HOST: میزبان MySQL (پیش‌فرض 127.0.0.1)
- DB_PORT: پورت MySQL (پیش‌فرض 3306)
- DB_NAME: نام پایگاه داده (پیش‌فرض taskflow)
- DB_USER: نام کاربری MySQL
- DB_PASS: گذرواژهٔ MySQL
- DB_CHARSET: مجموعه‌کاراکتر (پیش‌فرض utf8mb4)

فایل .env.example صرفاً الگو است؛ PHP به‌صورت خودکار آن را بارگذاری نمی‌کند. اطلاعات محرمانه را در Git commit نکنید.

## ۵. اجرای برنامه

از ریشهٔ پروژه اجرا کنید:

    php -S localhost:8000

سپس آدرس http://localhost:8000 را در مرورگر باز کنید.

## ۶. عیب‌یابی

- **خطای اتصال دیتابیس:** روشن بودن MySQL و مقادیر اتصال را بررسی کنید.
- **خطای درایور PDO:** افزونهٔ pdo_mysql را در تنظیمات PHP فعال کنید.
- **نمایش نادرست فارسی:** مطمئن شوید فایل‌ها با UTF-8 ذخیره شده‌اند و دیتابیس از utf8mb4 استفاده می‌کند.
- **خطای مجوز:** کاربر دیتابیس باید مجوزهای لازم برای خواندن و نوشتن جدول tasks را داشته باشد.

## نکتهٔ انتشار

برای محیط واقعی، از HTTPS استفاده کنید، خطاهای PHP را به بازدیدکننده نمایش ندهید، اعتبارنامه‌ها را خارج از مخزن نگه دارید و برای دیتابیس یک کاربر محدود و اختصاصی بسازید.
