# راهنمای مشارکت

از علاقه‌مندی شما به بهتر کردن TaskFlow سپاسگزاریم.

## روند پیشنهادی

1. مخزن را Fork کنید.
2. برای تغییرتان یک شاخه بسازید: feature/my-improvement
3. تغییرات را کوچک و مشخص نگه دارید.
4. پیش از ارسال، صفحات اصلی و عملیات ساخت، ویرایش و حذف را آزمایش کنید.
5. یک Pull Request با توضیح روشن دربارهٔ تغییرات باز کنید.

## استاندارد کدنویسی

- از PHP سازگار با نسخهٔ 8.1 یا بالاتر استفاده کنید.
- برای کوئری‌های دیتابیس از prepared statement استفاده کنید.
- خروجی کاربر را با تابع e() escape کنید.
- برای فرم‌های تغییردهندهٔ داده، اعتبارسنجی CSRF را حفظ کنید.
- نام متغیرها و توابع باید توصیفی باشند.
- رابط کاربری باید در موبایل و دسکتاپ قابل استفاده بماند.

## گزارش باگ

در گزارش خود، مراحل بازتولید، رفتار مورد انتظار، رفتار مشاهده‌شده و نسخهٔ PHP/MySQL را بنویسید. اطلاعات محرمانه یا گذرواژه‌ها را ارسال نکنید.

## پیشنهاد قابلیت

هدف قابلیت، تجربهٔ مورد انتظار و هر تغییر احتمالی در ساختار دیتابیس را توضیح دهید.
